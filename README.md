# Notty

A local-first notes app for Linux with the feel of Apple Notes. Notes are plain Markdown files you own; a SQLite index makes them searchable.

Status: v1 in planning. See `docs/SPEC.md` for scope and `docs/ARCHITECTURE.md` for the module map.

## Build

```bash
npm install
npm run tauri dev
npm run tauri build
```
